# GameLator 1.0

**GameLator 1.0** is an Android application that lets you run Windows (x86_64) applications and games with Wine and Box86/Box64.

This is a rebranded and customized version based on the excellent open-source project **Winlator** by BrunoSX.

The goal of this fork is to provide a modern **PlayStation 5 inspired user interface** while keeping all the powerful compatibility features of Winlator.

## Original Project
- Main repository: https://github.com/brunodev85/winlator
- App source (this fork is based on): https://github.com/brunodev85/winlator-app
